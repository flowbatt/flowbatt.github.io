Validation
----------
All three WOFF2 files were parsed with the existing local fontTools package.
They report Source Sans 3, version 3.052, the expected OS/2 usWeightClass
(400/600/700), no fvar variable-font table, and OS/2 fsType=0.

All three Unicode cmaps correctly map U+00B1 to plusminus and U+2212 to minus.
Greek coverage was verified for Delta, Theta, Sigma, Omega, alpha, beta,
gamma, delta, theta, lambda, mu, pi, sigma, phi, and omega. Latin text, digits,
spaces, and basic punctuation used on the page are covered as well.

The active CSS declares only the Source Sans 3 family. The schematic retains
its original 700 weight, font sizes, geometry, palette, data, axes, and timing.
Its SVG background contains no text/font/style nodes or embedded font data;
all visible schematic text is in the HTML/inline-SVG overlay and inherits
Source Sans 3. No background regeneration was required.

Historical Computer Modern and STIX assets/licenses remain as provenance for
previous iterations, but their @font-face declarations have been removed and
they are not loaded by the current font stylesheet. No italic face is needed
by the current upright page and schematic typography.
