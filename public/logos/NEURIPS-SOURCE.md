# NeurIPS logo review

Reviewed: 2026-11-22.

## Current decision

The FlowBatt page retains the conference name as ordinary venue text. No
NeurIPS logo has been downloaded for inclusion, recreated, or added to the
page. This follows the user's request to include logos only if their use is
allowed; the reviewed sources do not establish permission for this project
page.

Asset filename and SHA-256: not applicable; no logo asset was acquired.

## Official sources

- [NeurIPS media kit](https://neurips.cc/public/MediaKit): publicly provides
  the official logo in SVG and PNG formats.
- [NeurIPS policy, “Trademarks”](https://neurips.cc/Help/Policy): states that
  the named marks and logo “cannot be used without written permission from
  the NIPS Foundation Office.”

The policy uses the legacy **NIPS** name and refers specifically to the
**NIPS logo**. It does not expressly discuss the newer NeurIPS artwork or
accepted-paper project pages. Applying this permission requirement to the
current NeurIPS logo is therefore a cautious interpretation, not an explicit
project-page prohibition. The media kit provides the files but supplies no
logo-specific license or accepted-paper exception that resolves this point.

## Official asset locations for a later authorized inclusion

These URLs were obtained directly from the media kit, not from a third-party
logo collection:

- SVG: <https://neurips.cc/media/Press/NeurIPS_logo.svg>
- PNG, horizontal: <https://neurips.cc/media/Press/NeurIPS_logo.png>
- PNG, stacked: <https://neurips.cc/media/Press/NeurIPS_logo_stacked.png>

Written authorization or newer applicable guidance would resolve the open
permission question. If that evidence is supplied, record it here and acquire
the unmodified official asset with its SHA-256. No contact with NeurIPS has
been made during this review.

## Distinguishing evidence from assumptions

Public availability of a media-kit download is not itself an explicit logo
license. Paper acceptance establishes the venue association, but the reviewed
sources do not say that acceptance automatically grants logo-use permission.
The policy is the reason for leaving out the image; this decision does not
assert that ordinary factual venue text is prohibited.
