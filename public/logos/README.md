# University affiliation logos

Retrieved 2026-11-22 from official university sites for the confirmed author affiliations on the FlowBatt project page. Files are byte-for-byte originals: no recoloring, cropping, path edits, or changes to their aspect ratios. Render with proportional sizing and descriptive alternative text. These are university marks, not assets covered by the project’s code license.

## TU Braunschweig

- File: [`tu-braunschweig.svg`](./tu-braunschweig.svg), 22,864 bytes; `viewBox="0 0 198 74"` (source dimensions 260 × 97).
- [Official corporate-design guidance](https://www.tu-braunschweig.de/en/press/corporate-design-of-tu-braunschweig).
- [Original public website-header SVG](https://www.tu-braunschweig.de/_assets/333388531e987d8449e2f895c74a522b/Images/Logos/tu-braunschweig_logo.svg?1786702739), linked by the official guidance page’s HTML.
- SHA-256: `e37f4fe5ab305cf6c906fb030c0bb0642e87c5273cea41334b0b9c01f303d0c9`.

The official rules require the seal, university name, and rectangular band to remain one unit, with unchanged shape and proportions. Retain the supplied red and white. Use “TU Braunschweig” or “Technische Universität Braunschweig” in accessible/visible labels; the guidance rejects abbreviations such as “TUBS”. The corporate-design rules apply to university institutes’ and facilities’ publications.

The dedicated toolbox download requires university login and returned a 403. This file instead comes from the separately public official website header; no protected download was accessed. Using the intact mark to identify affiliated authors is the project’s interpretation of the institutional guidance, not a blanket third-party license or individualized university approval.

## TU Clausthal

- File: [`tu-clausthal-small.svg`](./tu-clausthal-small.svg), 3,925 bytes; `viewBox="0 0 91.73 17.07"`.
- [Official logo downloads and usage rules](https://www.presse.tu-clausthal.de/en/service/corporate-design/logo).
- [Original simplified color SVG](https://www.presse.tu-clausthal.de/fileadmin/Sites/Presse/Images/Corporate_Design/Logo/Logo_TUC_de_CMYK_klein.svg), the official page’s “Simplified version” SVG download.
- SHA-256: `76065f4fe1a0dc9a82a1b16343c21c2d3633eafcd9e1734d2b39be20b5c0d2a5`.

The official rules favor color, allow proportional scaling only, require a supplied version, and prohibit using the square without the “TU Clausthal” lettering. The simplified version is required below 40% of original size (large-square height below 10 mm), making this the appropriate supplied lockup for the compact affiliation row. Preserve its original green and gray.

The public download page does not impose an additional approval step for the affiliated-author use described here. This records the published conditions and the project’s affiliation-use interpretation, not a general third-party license. The SVG is listed in the print/CMYK downloads but contains native hexadecimal SVG color values; it is retained without color conversion.
